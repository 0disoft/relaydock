# 01. Scope and Non-Goals

## Stage 0

- Wails v3 tray shell
- MCP STDIO bridge
- Local IPC contract
- Consultation state machine
- ContextPack manifest
- Secret-redaction contract
- OpenAI Responses golden fixture
- Protocol stream state machine
- HTTP health server
- Initial PostgreSQL schema and migration contract

## Stage 1

- Single OpenAI Responses provider
- Explicit API expert route
- Manual web handoff
- Virtual keys
- Signed runtime snapshots
- Usage events
- Basic Wails UI

## Stage 2

- Anthropic Messages
- Strict, compatible, and passthrough compiler modes
- Provider health and deterministic routing
- Local credential store
- Windows autostart
- Updater canary

## Stage 3

- Gemini
- Managed Control Plane
- Remote MCP OAuth
- Money-platform hold and capture
- Cloud console

## Explicit Non-Goals

- ChatGPT web DOM automation
- A shared cloud pool of consumer subscription accounts
- Arbitrary JavaScript plugins
- A proprietary RAG platform
- A prompt marketplace
- An agent builder
- A semantic cache
- Kubernetes-first deployment
- Kafka-first adoption
- Claims of perfect compatibility with every model
